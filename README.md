# LocalAlgebrasLean

Nets of local algebras and the quasi-local algebra of a quantum spin system, formalized in Lean 4
over Mathlib.

A quantum system with regions assigns to each region `O` an algebra `𝒜(O)` of observables; larger
regions carry larger algebras, and observables of separated regions commute. For a lattice of
`d`-level systems, `𝒜(X)` is the matrix algebra of a finite region `X`, and the observables of the
infinite lattice form the quasi-local algebra, the norm closure of the union of the `𝒜(X)`. The
library defines these objects once, for use by formalizations of quantum field theory, quantum
cellular automata, propagation bounds and tensor networks.

## What is proved

| | Main results |
|---|---|
| Nets | Nets of local algebras over regions with an orthogonality relation; local commutativity, covariance, nets generated by sets |
| The qudit net | Matrices local to a region, with site-dependent dimensions; local commutativity and relabelling covariance |
| The quasi-local algebra | The embedding of each local matrix algebra is a unital, injective, isometric star homomorphism, compatible with `m ↦ m ⊗ 1`; the quasi-local net is locally commutative and covariant under symmetries of the lattice; it is independent of the reference configuration and agrees with the qudit net in finite volume |
| Universal property | Compatible families of unital star homomorphisms out of the local algebras extend uniquely through the quasi-local algebra; any other construction, such as the abstract inductive limit, is isomorphic to this one |

The precise statements are the 21 theorems of [`verify/CORE.md`](verify/CORE.md). Conventions are
listed in `CONVENTIONS.md`.

## Verification

The 21 theorems of the core are eleven main results, five statements that describe the
library's definitions in Mathlib's terms, and five examples on the chains `ℕ` and `ℤ` in which the
hypotheses hold and the algebras are not trivial. `verify/Challenge.lean` states them without
proofs, and `verify/Solution.lean` proves them from the library. The command

```
lake comparator --config verify/comparator.json --paranoid
```

checks that every proved theorem has exactly the stated form, that no axioms beyond `propext`,
`Classical.choice` and `Quot.sound` are used, and that Lean's kernel and four independently
written proof checkers accept every proof. A reader who accepts the 21 statements therefore need
not read any proof. The same check runs on GitHub at every change.

`lake comparator` is the proof judge maintained by the Lean developers for proofs whose author is
not trusted, including proofs produced by AI; see
[leanprover/comparator](https://github.com/leanprover/comparator) and the chapter
[Validating a Lean Proof](https://lean-lang.org/doc/reference/latest/ValidatingProofs/#validating-comparator)
of the Lean reference manual. Among its checkers are
[lean4lean](https://github.com/digama0/lean4lean) and [nanoda](https://github.com/ammkrn/nanoda_lib).
On Linux it isolates the compiled code in a sandbox; elsewhere it needs the option
`--inadvisably-no-sandbox`.

## Build and verify

With the Lean installer `elan`:

```
git clone https://github.com/etjoa002/LocalAlgebrasLean
cd LocalAlgebrasLean
lake exe cache get          # download the precompiled Mathlib
lake build LocalAlgebrasLean
lake comparator --config verify/comparator.json --paranoid
```

The library depends only on [Mathlib](https://github.com/leanprover-community/mathlib4); the
versions of Lean and Mathlib are fixed in `lean-toolchain` and `lake-manifest.json`.

## Methods of proof

The quasi-local algebra is realized on `ℓ²` of the configurations that differ from a reference
configuration `s₀` at finitely many sites, the representation of the product state of `s₀`. A
matrix unit of a finite region acts there as a partial permutation of configurations. Mathlib has
no C*-inductive limits; the universal property identifies this concrete algebra with any other
construction.

## Numerical checks

`checks/quasilocal_check.py` (Python with NumPy, `checks/requirements.txt`) tests the
finite-dimensional content of the construction on small windows of sites, in exact integer
arithmetic where possible.

group actions; `Qudit/` the qudit net and the quasi-local algebra; `verify/` the core.

## Status

The library is under development, and this repository is updated as the work progresses; see
`CONTRIBUTING.md` for problem reports and suggestions. The library is kinematic, and dynamics
belongs to the libraries built on it. Planned next are nets of graded algebras, as fermionic
lattice systems require, and lecture notes. Candidates for later theorems: the representations for
reference configurations that differ at infinitely many sites are inequivalent (J. von Neumann,
Compositio Math. 6 (1939) 1–77); on the infinite lattice, the projection onto the reference state
lies at distance `1/2` from the local algebra of every proper region.
